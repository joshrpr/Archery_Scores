# Ranch Horizon maintained source

`ranch-source.png` is the exact 512 × 512 PNG originally embedded in the existing ranch logo and the approved Ranch Horizon prototype. It is frozen, unbranded source artwork. Do not overwrite it with an icon export or generate a substitute landscape.

`ranch-horizon.svg` is the maintained 128 × 128 selected composition. It references that source directly: solid OD upper field, the original aerial crop below y=49 (source viewBox 48 200 416 280), cream aiming arcs, and the orange arrow.

Run `node scripts/brand-web.mjs` from the repository to generate the self-contained production mark `ibo-scorer/icons/ranch-horizon.svg`. Native and raster exports must consume this maintained arrangement and frozen source, never a previously generated icon. Adaptive masks and safe-area variants belong to the native asset implementation.

The historical approved prototype remains under `assets/prototypes/ranch-brand/marks/`; it is reference evidence, not the ongoing input path.
