# Ranch aerial identity studies

The ranch remains central in all three proposals. Open `index.html` to compare large icons, 48/32px launcher examples, circle and rounded-square masks, grayscale, and the Velocity OD header.

- Ranch Horizon retains the broad aerial view below an OD green upper panel and familiar orange arrow/aiming arcs.
- Ranch Emblem crops the actual aerial into a circular medallion with an orange arrow crest.
- Ranch Frame lets the aerial occupy most of the icon with an OD green border and arrow badge.

The ranch imagery is embedded directly from the existing `ibo-scorer/icons/icon-512.png`, with its bytes unchanged. SVG viewports select the aerial portion below the original blue sky and arrow. Different window shapes crop different amounts of the same source. The ranch was not regenerated or replaced with a different landscape. No separate, unbranded source photograph was found in the project.

Source SVGs embed that image for portability; PNGs are direct 512×512 browser renders. This is a prototype composition of existing artwork with new vector framing. Existing production icons and the previous logo studies remain unchanged. Native adaptive layers are not yet implemented.
